How it worksNasıl çalışır

A workflow, not a mood.Bir ruh hali değil, bir iş akışı.

Ground in a referenceReferansa dayan

Reads your project's source for real colors, radii, spacing and animation timings, or asks for one. It does not invent when something real exists.Projenin kaynağından gerçek renk, radius, boşluk ve animasyon sürelerini okur, ya da bir referans ister. Gerçeği varken uydurmaz.

Generate a design languageTasarım dili üret

An OKLCH palette with tinted neutrals, fixed to WCAG, light and dark. A type scale, motion tokens, one icon weight. One concept sentence.Boyalı nötrlerle OKLCH paleti, WCAG'a göre düzeltilmiş, açık ve koyu. Yazı ölçeği, hareket tokenları, tek ikon kalınlığı. Tek cümlelik konsept.

One board per stateDurum başına bir tahta

Idle, hover, empty, error, loading, overflow, focus. Plus a motion storyboard, a font comparison, themes and a tokens board.Boşta, hover, boş, hata, yükleniyor, taşma, odak. Ayrıca hareket storyboard'u, font karşılaştırması, temalar ve token tahtası.

Gate against slopSlop kapısı

A linter scores defaults, neon, glow, gradients, emoji, cliche palettes and empty boards. A receipt proves the files really exist.Bir denetleyici varsayılanları, neonu, parlamayı, gradyanı, emojiyi, klişe paletleri ve boş tahtaları puanlar. Teslim fişi dosyaların gerçekten var olduğunu kanıtlar.

Deliver a canvasCanvas teslim et

One HTML file with an infinite surface, focus mode and per-board download. Works offline, no build step, no dependencies.Sonsuz yüzey, odak modu ve tahta başına indirme olan tek HTML dosyası. Çevrimdışı çalışır, derleme ve bağımlılık yok.

Iterate narrowly, then hand offDar iterasyon, sonra aktarım

React to one element and only that changes. Then export tokens and compare the build to the boards.Tek bir öğeye tepki ver, yalnızca o değişir. Sonra tokenları aktar, yapıyı tahtalarla karşılaştır.

InstallKurulum

One command. You pick the agents.Tek komut. Ajanları sen seçersin.

curl -fsSL https://raw.githubusercontent.com/lunanoir21/spec-mockup-design/main/install.sh | bash

It downloads the skill, then shows a picker. Agents found on your machine are pre-selected. It never overwrites an existing file and only removes the links it created (--uninstall). Needs Python 3.8+; Chromium or Chrome is optional, for screenshots.Skill'i indirir, sonra bir seçici gösterir. Makinende bulunan ajanlar önceden seçili gelir. Var olan hiçbir dosyanın üstüne yazmaz, yalnızca kendi koyduğu bağlantıları kaldırır (--uninstall). Python 3.8+ gerekir; ekran görüntüleri için Chromium veya Chrome isteğe bağlı.

Flags: --detected --yes --agents claude,codex --all --list --dry-run --instructions --copyBayraklar: --detected --yes --agents claude,codex --all --list --dry-run --instructions --copy
