Direction & reference680×520

No reference project was supplied. Structure borrowed from the browser popup convention; palette and type are proposed, not copied.

A filing index for open tabs: bone-paper slips on a graphite frame, the current tab pulled forward with its corner turned down, and one brass signal doing all the accent work.

One bold move

A Deployments · acme-consoleconsole.acme.io · opened 2h ago 2m

The current tab is the only element allowed to be loud: a folded top-left corner in brass, a raised paper fill and bold title. No left accent bar anywhere — status is carried by shape and weight.

Palette

Hue 78 (brass/ochre) — this is a utility instrument, not a brand, so the accent stays desaturated and appears on exactly two things: the current tab and the one primary action. Neutrals are tinted toward the same hue; brick #953e37 is reserved for the single destructive action, and it never appears without an icon and a verb.

Type

Cantarell for the UI (a real desktop face, dense at 11–14 px), Bricolage Grotesque for the one hero numeral, JetBrains Mono for hosts and URLs — the only place mono earns its keep.

Borrowed vs. invented

  • Borrowed: the 380 px popup column; 40 px row rhythm; hairline separation; chevron-collapsed groups; ⌘K / Esc conventions; the footer action bar.
  • Invented: the palette and the type pairing; the folded-corner current marker (replacing the usual coloured rail); the "reclaimable memory" line; the folded-slip hover.
