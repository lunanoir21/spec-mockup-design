1 · reference — concept, provenance, what is borrowed1120×610

A quiet kitchen-timer instrument.

Bone paper, one deep brick dial, one big tabular numeral. The dial that ticks in the menu bar is the same object as the dial inside the popover — it changes scale, never shape. That is the whole idea; everything around it stays plain.

No reference project was supplied — so the plan is stated, not borrowed

DecisionValue and reason
Accent hueOKLCH hue 32 → #9a3a29. Reason: the pomodoro is a tomato; a kitchen timer reads brick, not SaaS blue.
NeutralsHue 32 family at chroma 0.0025–0.0053 (#f5f3f2 / #131111). Nearly achromatic on purpose: macOS chrome owns the surface tint, the accent owns the chroma.
TypeUI Cantarell 11–15 px (a humanist UI face, not Inter/system). Numeral Bricolage Grotesque 45 px for the one hero number. JetBrains Mono only for keys and hexes.
BorrowedmacOS conventions only: 24 px menu bar, 336 px popover, 13 pt popover body, hairline separators, a highlighted status item while its popover is open, Esc/click-out to dismiss.
NewThe 25-tick dial, the numeral face, the brick/celadon/amber state vocabulary, and the rule that a paused session is drawn hollow — form encodes state, not hue alone.

Palette palette.py --hue 32|166|78 · scales scales.py --target widget --density compact. Two accepted lint flags: dead-greys (the near-achromatic neutral ramp is deliberate, see Neutrals) and cluster-look risk avoided by keeping neutrals under chroma 0.006.

One dominant element per screen

focus · brick #9a3a29a session is running · solid arc, filled buttons
rest · celadon #006f50a break is running · solid arc, "Skip" leads
held · amber #7c5500paused by the person · dashed arc, dimmed numeral
danger · oxblood #9f322dreset / clear history · always with a trash icon and a verb

Every state is legible without colour: the arc is solid, dashed or absent, the numeral carries the value, and the caption names the state in words. Contrast is checked on the Tokens board.

Open question for the build: May the status item use a custom numeral face? NSStatusItem.attributedTitle allows it, but the system face is the safer default; the bar boards show the custom face, with the fallback noted on board 2.

Concept sentence, palette provenance, borrowed-vs-new split, and the accepted lint flags. Nothing here is a screen — it is the contract the other seven boards must obey.
