Concept760×420
Concept

A garden you check on, not a scoreboard you lose to.

One calm moss-green, tinted neutrals and a single numeral face for streaks. Rows stay quiet, the ring shows today, and a missed day looks like a gap in the grid, not a red failure. The only loud thing on screen is the next small action.

Why it looks like this
  • Hue 150 (moss) from the subject: growth, not fitness neon.
  • Generated with palette.py, mood calm, analogous. Every text pair passes AA.
  • Missed days use the neutral line color, never danger red.
  • Display face (Bricolage Grotesque) for numerals only; Plex Sans for the rest.
Reference
No project supplied. Structure borrowed from the iOS Health/Reminders conventions (tab bar, large title, sheet for creation). Palette, type, icons and copy are new. Dates and names are examples.
